# Code of Conduct

We are committed to a welcoming, harassment-free experience for everyone.

**Expected behavior:** be respectful, welcome different viewpoints, give and accept constructive feedback gracefully.

**Unacceptable behavior:** harassment, discrimination, personal attacks, trolling, or publishing others' private information.

Maintainers may remove, edit, or reject contributions that violate this code and may ban contributors for behavior they deem inappropriate. Report concerns by opening an issue or contacting a maintainer privately.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
